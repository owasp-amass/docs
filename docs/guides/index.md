# :material-book-open-variant: Guides

Hands-on walkthroughs for getting started with OWASP Amass and for going
deeper. If you are looking for reference material instead, see
[Using the Framework](../usage/index.md), the
[Open Asset Model](../open_asset_model/index.md), and
[Configuration](../configuration/index.md).

- **[Your first enumeration](first-enumeration.md)** — install Amass, run your
  first collection, and read the results.
- **[Map an attack surface](attack-surface-report.md)** — turn a domain into an
  attack-surface report: subdomains, services, exposure and change over time.
- **[Investigate with AI](investigating-with-ai.md)** — ask plain-language
  questions, explore through an assistant, and review what the model proposes.
- **[Organizations and corporate groups](organizations-and-groups.md)** —
  identify the company behind a domain, place it on the map, and roll up a
  corporate group's funding.
